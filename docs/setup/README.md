# docs/setup/

This folder will contain environment setup guides and developer onboarding documentation for AIRA.

## What will go here later

- **Development environment setup** — Node.js, Python, Rust, Tauri prerequisites.
- **Local model setup** — How to install Ollama and download recommended models.
- **Voice setup** — Whisper and Piper installation and configuration.
- **Database setup** — SQLite initialization and migration instructions.
- **First-run guide** — Step-by-step instructions to build and run AIRA from source.
- **Troubleshooting** — Common issues and fixes for the target laptop.

## What does NOT go here

- Architecture decisions (use `docs/decisions/`).
- System design documents (use `docs/architecture/`).
- User-facing help documentation (that will be inside the app).
- Source code or scripts (use `scripts/`).

## Current status

No setup guides exist yet. The project is in the planning/structure phase.
