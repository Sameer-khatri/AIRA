# docs/architecture/

This folder contains high-level system design documents for AIRA.

## What goes here

- `system_overview.md` — What AIRA is, how the major parts connect, and what runs locally.
- `data_flow.md` — Step-by-step flows showing how data moves through AIRA for common user scenarios.
- Future diagrams showing component relationships, API boundaries, and deployment architecture.

## What will go here later

- Detailed module-level architecture documents.
- API contract specifications.
- Database schema diagrams.
- Model routing and resource management documentation.

## What does NOT go here

- Implementation code (use `apps/` or `core/`).
- Product requirements (use `docs/prd/` or `IMP/`).
- Setup instructions (use `docs/setup/`).
