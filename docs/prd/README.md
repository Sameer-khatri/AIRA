# docs/prd/

This folder contains PRD references and summaries for the AIRA project.

## What goes here

- Summaries and quick-reference guides derived from the locked PRDs.
- Feature breakdowns extracted from the main PRDs.
- Requirement checklists for implementation verification.

## What will go here later

- Version-specific requirement summaries (V1, V1.5, V2.0).
- Feature acceptance criteria checklists.
- PRD change logs for future versions.

## What does NOT go here

- The original PRD files. Those live in `IMP/` and must not be modified.
- Architecture documentation (use `docs/architecture/`).
- Setup guides (use `docs/setup/`).

## Original PRDs

The locked PRD originals are in the project root under `IMP/`:

- `AIRA_Product_Requirements_Document_v1.0.md`
- `AIRA_UI_UX_Product_Requirements_Document_v1.0.md`
- `AIRA_Tech_Stack_Product_Requirements_Document_v1.0.md`
- `AIRA_MVP_Implementation_Roadmap_v1.0.md`
