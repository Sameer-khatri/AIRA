# docs/

This folder contains all project documentation for AIRA.

## What goes here

- **architecture/** — System design, data flow diagrams, and technical overviews.
- **prd/** — Product requirement document summaries and references.
- **setup/** — Environment setup guides, installation steps, and developer onboarding.
- **decisions/** — Architecture decision records (ADRs) explaining why things are built a certain way.

## What does NOT go here

- Source code or scripts (use `apps/`, `core/`, or `scripts/`).
- Raw PRD originals (those stay in `IMP/`).
- User-facing help documentation (that will live inside the app later).
- Meeting notes or random brainstorming (use a separate notes tool).

## How to use

Start with `architecture/system_overview.md` to understand how AIRA is structured, then read `architecture/data_flow.md` to see how data moves through the system.
