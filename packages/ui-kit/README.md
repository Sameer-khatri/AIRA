# packages/ui-kit/

Reusable UI components and design tokens for AIRA's visual identity.

## What goes here

- Design tokens (colors, typography, spacing, shadows) matching the UI/UX PRD.
- Reusable React components (buttons, cards, inputs, badges, modals).
- Icon wrappers and consistent styling utilities.

## What will go here later

- AIRA's dark futuristic theme tokens (bg-void, bg-deep, cyan-core, violet-core, etc.).
- Component library built on Radix UI primitives.
- Animation presets using Framer Motion.

## What does NOT go here

- Page-level components or routes (those go in `apps/desktop/`).
- Backend code.
- Avatar art assets (use `avatar/assets/`).

## Current status

Structure only. The design system will be built during Milestone 0 / Sprint 1.
