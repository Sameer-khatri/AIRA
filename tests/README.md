# tests/

Cross-module and integration tests.

## What goes here
- End-to-end tests that span across the desktop app, backend, and LLM integration.
- Hardware tests to measure VRAM, RAM, and latency.
- Privacy compliance tests.

## What does NOT go here
- Unit tests specific to a single app (e.g. backend unit tests go in `apps/backend/tests/`).

Not yet implemented.
